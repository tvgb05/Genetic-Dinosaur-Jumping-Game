# Genetic-Dinosaur-Jumping-Game

## Install library
`pip install -r requirements.txt`
## Run
`py main.py`
## If cannot run properly
- Make sure you install python 3.11+
- Create an ENV in the folder: `py -3.11 -m env env`
- Activate: `env\Scripts\activate`
- Then install the requirements.txt
## Tweaking
Edit properties in config.json
